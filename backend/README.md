# Backend

Este módulo é responsável pela API principal do sistema **Cesta Inteligente**, desenvolvida em **Java com Spring Boot**.

## Responsabilidades

- expor os endpoints da aplicação;
- receber as requisições do frontend;
- aplicar as regras de negócio;
- interagir com o banco de dados MySQL;
- integrar-se ao módulo de otimização em Python.

## Tecnologias previstas

- Java
- Spring Boot
- Spring Data JPA
- MySQL
