# Módulo de Otimização em Python

Este módulo é responsável pelo processamento da lógica de otimização do sistema **Cesta Inteligente**.

## Responsabilidades

- receber os dados consolidados da simulação;
- aplicar o algoritmo baseado no **Problema da Mochila 0-1**;
- considerar orçamento, itens desejados e restrições;
- devolver ao backend a melhor combinação de produtos.

## Tecnologias previstas

- Python 3.x
- biblioteca(s) de apoio ao processamento matemático, se necessário
