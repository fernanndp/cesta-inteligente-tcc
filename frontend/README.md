# Frontend

Este módulo é responsável pela interface web do sistema **Cesta Inteligente**, desenvolvida em **React.js**.

## Responsabilidades

- apresentar a interface ao usuário;
- permitir a seleção da rede de supermercado;
- receber orçamento, lista base e restrições;
- exibir a cesta otimizada e a lista final de compras;
- consumir a API do backend.

## Tecnologias previstas

- React.js
- JavaScript
- HTML
- CSS
