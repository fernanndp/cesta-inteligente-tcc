# Diagramas

Esta pasta concentra os diagramas utilizados na modelagem do sistema **Cesta Inteligente**.

## Organização

Os diagramas estão separados por tipo de visão:

- banco de dados;
- casos de uso;
- implantação;
- implementação;
- visão lógica.

## Objetivo

Facilitar a compreensão da arquitetura, do domínio e da implementação do sistema.
